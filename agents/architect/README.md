# Architect Agent

## Purpose

Designs technical architecture for workflows including system components, data flows, integrations, and infrastructure requirements.

## Responsibilities

- Component design
- Data flow modeling
- Integration pattern selection
- Technology stack recommendations
- Scalability planning
- Security architecture

## What Belongs Here

- Architect agent implementation
- Architecture patterns library
- Diagram generation (Mermaid, etc.)
- Prompt templates for architecture

## What Must NEVER Belong Here

- Code implementation
- Workflow execution
- Database operations

## Dependencies

- `llm.providers` - LLM reasoning
- `agents.analyst` - Receives specifications

# Analyst Agent

## Purpose

Analyzes requirements, constraints, and context to produce detailed specifications for workflow construction.

## Responsibilities

- Requirement parsing and normalization
- Constraint extraction
- Stakeholder identification
- Gap analysis
- Feasibility assessment

## What Belongs Here

- Analyst agent implementation
- Requirement analysis algorithms
- Specification generation
- Prompt templates for analysis

## What Must NEVER Belong Here

- Workflow execution
- Technical architecture decisions
- Database operations

## Dependencies

- `llm.providers` - LLM reasoning
- `agents.planner` - Receives planned tasks

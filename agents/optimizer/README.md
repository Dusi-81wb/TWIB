# Optimizer Agent

## Purpose

Continuously improves workflows through performance optimization, cost reduction, and efficiency gains.

## Responsibilities

- Bottleneck identification
- Cost analysis and reduction
- Parallelization opportunities
- Resource allocation optimization
- Caching strategy recommendations
- Model selection optimization

## What Belongs Here

- Optimizer agent implementation
- Optimization algorithms
- Cost modeling
- Prompt templates for optimization

## What Must NEVER Belong Here

- Workflow execution
- Architecture design
- Database operations

## Dependencies

- `llm.providers` - LLM reasoning
- `llm.router` - Model routing data
- `analytics` - Performance metrics
- `workflows.executor` - Execution profiles

# Diagrams

## Purpose

Store Mermaid diagram sources describing the TWIB system visually.

## Responsibilities

- Maintain diagram source files (`.mmd`)
- Reflect the current architecture in visual form
- Serve as references for documentation, reviews, and presentations

## What Belongs Here

- Mermaid source files (`.mmd`)
- Diagrams for architecture, deployment, workflows, agents, flows, and schemas

## What Must NEVER Belong Here

- Generated/rendered images (unless explicitly requested)
- Implementation code
- Diagrams unrelated to the TWIB system

## Dependencies

- `docs/architecture.md` — diagrams must match the documented architecture
- Diagrams can be rendered via any Mermaid-compatible viewer

## Future Phases

- Populate diagram sources as modules are designed and implemented
- Add new diagrams for future modules (payments, analytics, realtime)

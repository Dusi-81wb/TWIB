# Examples

## Purpose

Provide illustrative examples for workflows, APIs, tools, prompts, and architecture patterns.

## Responsibilities

- Showcase practical usage of TWIB concepts
- Provide reference examples for developers and AI agents
- Serve as templates for future documentation

## What Belongs Here

- Workflow examples
- API request/response examples
- Tool usage examples
- Prompt examples
- Architecture pattern examples

## What Must NEVER Belong Here

- Implementation code
- Live production data
- Placeholder or incomplete examples (once populated)

## Dependencies

- `docs/architecture.md` — patterns must comply with the architecture
- `docs/api/` — API examples align with API docs
- `docs/prompts/` — prompt examples align with prompt specs

## Future Phases

- Populate examples as modules are implemented
- Add real-world enterprise scenarios
